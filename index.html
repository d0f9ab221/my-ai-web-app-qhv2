How to Fix "In-Game Black Avatar" Error

1. Keep Original File Size

Always use Safe Pad / Truncate mode. If the file size changes, the game's index file will reject the asset, rendering it black.

2. Match Block Size Exactly

Ensure the ASTC Block Size matches the original texture (usually 6x6 or 4x4). Our Smart Optimizer auto-detects this for you.

3. Enable Free Fire Fix

Keep the Free Fire Compatibility Fix checked. This forces standard Void-Extent block encoding which is fully supported by mobile GPUs.
